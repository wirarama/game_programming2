Taruh file gambar tokoh di sini (PNG/JPG disarankan, ukuran persegi minimal 300x300px
akan terlihat paling bagus, tapi ukuran apa pun otomatis di-scale).

Nama file bebas, yang penting path-nya dicocokkan di data/characters.json,
contoh:
  "image": "assets/images/rei.png"
  "ending": { "image": "assets/images/rei_ending.png" }

Jika file belum ada / typo, game TIDAK akan crash — otomatis menampilkan
kotak warna + inisial nama sebagai gambar sementara.
